Role-based access control for React applications

rbac-manager is a React and TypeScript library for rendering permission-aware interfaces, guarding routes, and building reusable admin master-data screens.

Install from npm View on GitHub

React permissions and admin UI features

  • Permission guards
    Conditionally render UI with permission and route checks.
  • Backend adapters
    Configure API response transformations and endpoint contracts.
  • Roles and permissions
    Use role and permission management components in your application.
  • Admin master-data views
    Build configurable entity, department, designation, and employee screens.
  • React and TypeScript
    Use typed APIs with ESM and CommonJS package builds.
  • Flexible permission keys
    Adapt permission naming with aliases and a configurable resolver.

Quick start

Install the package and React peer dependencies:

npm install rbac-manager

Wrap your application with the providers and render content only when the required permission is present:

import {
  Can,
  createRBACConfig,
  PermissionProvider,
  RBACConfigProvider,
} from 'rbac-manager';

const config = createRBACConfig({
  apiBaseUrl: 'https://api.example.com',
  getToken: () => localStorage.getItem('token'),
});

export function App() {
  return (
    <RBACConfigProvider config={config}>
      <PermissionProvider>
        <Can do="projects.create">
          <button type="button">Create project</button>
        </Can>
      </PermissionProvider>
    </RBACConfigProvider>
  );
}

Keep authorization on the server

Client-side permission checks control what the interface displays; they do not secure your API. Always enforce authentication and authorization on the server for every protected operation. Client-side checks can be bypassed.
